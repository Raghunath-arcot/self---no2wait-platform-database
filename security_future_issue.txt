Your frontend is blank because your backend is returning a **cyclic JSON structure**.

Look at your response:

```
question
  → options
      → question
          → options
              → question
                  → options
                      → question
                          → ...
```

It keeps nesting infinitely.

That’s why:

* Browser freezes
* React renders nothing
* Page becomes blank
* Network tab shows huge 108KB JSON

This is a **classic JPA bidirectional relationship infinite recursion problem**.

--

You have something like:

```java
class Question {
    @OneToMany(mappedBy = "question")
    List<Option> options;
}

class Option {
    @ManyToOne
    Question question;
}
```

When Jackson serializes:

Question → options → question → options → question → options → ...

Infinite loop.

# ✅ Correct Fix (Backend Only — No Frontend Changes Needed)

You must break the JSON recursion.

# ✅ OPTION 1 (Quickest Fix)

In `OptionEntity` add:

```java
import com.fasterxml.jackson.annotation.JsonIgnore;

@ManyToOne
@JoinColumn(name = "question_id")
@JsonIgnore
private QuestionEntity question;
```

That stops:

```
option → question → options → question
```

Now your JSON becomes:

```
Question
   options [
       { id, optionText, correct }
   ]
```

Clean. No recursion.
